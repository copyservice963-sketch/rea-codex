# Instruções do projeto

- Responda em português do Brasil.
- Este repositório é um espaço de trabalho para REA com Codex.
- Leia README.md antes de orientar instalação ou diagnosticar problemas.
- Verifique se as ferramentas REA estão disponíveis antes de afirmar que executou uma análise. Se estiverem ausentes, explique como configurar no ambiente atual.
- Baseie conclusões de análise em evidências e informe o que não foi verificado.
- Antes de analisar um alvo, confirme o caminho e o objetivo informados pelo usuário.
- Não inclua senhas, tokens, credenciais ou configurações pessoais de autenticação nos commits.
- Execute verificações proporcionais às mudanças e informe os resultados.
